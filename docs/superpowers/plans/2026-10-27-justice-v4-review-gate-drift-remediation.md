|---|---|---|
| Recognized slash command, init throws, `#justice=null`, or `#noOp` | No host-expanded command/`@file` parts escape to model; canonical BLOCK/REJECTED with no task dispatch | 1 |
| V2 admitted creation followed by immediate/restarted invocation | Same Gate/generation and spent rounds, one protected dispatch event, no fallback to Legacy or duplicate reviewer | 3–4 |

| Plan P0 with approved committed D0 but contradictory dirty/staged Design D1 | Actual adapter query/prompt returns only D0 content; D1 confined to diagnostic diff/status | 2, 5 |
| Stale CLEAR, changed Requirements/protocol, corrupt blob, alias or unsupported generic tool | Reject before read/dispatch; zero use of mutable Design as approved content and no mutation | 2, 5 |
