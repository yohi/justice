# Upstream Compatibility Audit Record

このファイルは upstream compatibility audit の監査証跡の正本です。監査手順は
[`docs/agents/upstream-drift.md`](../agents/upstream-drift.md) に定義し、各監査の結果は
このファイルへ調査日ごとのセクションとして追記します。

の full commit SHA、実行した検証コマンドと終了結果、観測した user flow、差分、残存差異、
受容した制限を記録します。`SPEC.md` には監査結果を重複して記録しません。
